Palmline is an offline poster studio for turning your photos into a coastal crime anthology cover. Arrange the panels, choose a color grade, and download square, portrait, or landscape PNGs.

Run `node serve.ts` with Node 22 and open `http://localhost:8080`. You can also open `app/index.html` directly.
